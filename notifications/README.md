# 通用 PNC Helper

正式版本：PNC `2.1.0`，PNC Helper `1.0.0`。位于主分支 `main`，历史测试分支和旧脚本保留。文件仍为 `PNC.user.js`、`PNC Helper.user.js`。

## 普通网页模式：篡改猴与脚本猫

Helper 在普通 HTTP/HTTPS 顶层网页运行；任何其他网页仍在运行时，可依据 Helper 自己的缓存检查截止时间，不要求 PTA 标签一直打开。**不是“永远运行”**：所有普通标签关闭、浏览器退出、页面冻结/丢弃、系统休眠会停止或延迟；恢复后仅提醒还未截止的题集。浏览器内部页和不允许注入的站点不覆盖。

1. 只保留一份 PNC 和一份 Helper，不要同时启用旧后台 Helper 副本。
2. 在 PNC 设置页“倒计时提醒”下面点击“复制 Helper 配对码”。浏览器需支持 Web Crypto 和 Web Locks。没有安全写锁则同步失败，不降级为不安全计数器。
3. 在 Helper 扩展菜单选择“配对”，粘贴配对码，确认来源并启用提醒。无需再单独授权。取消或无效内容不修改配对；同一公钥重新配对保留提醒缓存，更换公钥会在明确确认后清空旧提醒缓存。只接受公钥，不要填私钥、Token、Cookie 或 API Key。
4. 打开 PTA，在 PNC 设置底部启用倒计时提醒并选择提前天数。配对会立即请求同步，不刷新网页；其他站点配对后需打开 PTA 同步。
5. 菜单提供“配对”“提醒状态”“取消配对”，并新增“测试诊断”。“提醒状态”显示同步及启停状态，确认后切换所有标签的暂停/恢复；取消弹窗则不更改。“取消配对”需确认，清除 Helper 提醒缓存，不影响 PNC 答题缓存。系统是否显示通知仍取决于通知权限和系统设置。

主脚本私钥只在主脚本 GM 存储，Helper 仅持公钥和自己的提醒缓存。主签名序号用 PTA 同源 Web Locks 串行生成，Helper验证签名、时效与单调序号；页面不能伪造新配置，但恶意宿主仍能阻断同步。停止通知可直接在**Helper 扩展菜单暂停**，不要依赖可能未送达的网页关闭消息。仅关闭页面不会撤销最后确认账号；离线期间无法知道服务器注销、延期等变化。

### 多标签和通知结果

通用模式使用两管理器提供的 `GM_getTabs` / `GM_saveTab` 标签记录实现 bakery 互斥，不使用“超时抢锁”。冻结的持锁标签会阻塞其他实例，直到恢复或关闭；这是避免并行重复请求的取舍。仅支持每个标签一个顶层 Helper，缺少接口时停用。实际管理器的存储与生命周期语义仍需实机验证，不能据模拟承诺绝不重复。

篡改猴没有脚本猫的 `oncreate` 回执：调用未抛错只标为“已请求/结果未知”，不因缺回执盲目重发。明确失败最多有限退避重试；请求已发出后无法撤回。去重记录写入后若浏览器在调用前崩溃，可能漏掉该次提醒，这是保守避免重复的边界。勿把它当唯一提醒渠道。

### 脚本猫可选独立后台增强

保留原手动共享 GM 方案作为**替代模式**，不要与普通网页模式的另一份 Helper 同时使用：在同一 Helper 元数据加入 `@background` 和 `@storageName <主脚本实际UUID>`，保存后重新启用。由脚本猫后台调度，不依赖普通网页标签；没有 DOM 时只走既有后台模块，不走签名网页接收。需先在实际脚本猫版本核实后台元数据生效。

此模式会授予 Helper **整个主脚本 GM 存储**的读写能力，不是提醒键级授权；后台代码自限五个 `pnc-reminder-v2:*` 键。用户须理解并选择此权限范围，不能把普通公钥配对的隔离保证套用到后台共享模式。不要上传含本机 UUID 的定制文件。更改元数据可能改变存储空间，模式之间不承诺同步去重状态；旧数据不自动删除。

普通模式的公钥独立存储，更新代码不覆盖。旧版源码内填写的公钥不自动继承，请重新从菜单粘贴配对。后台模式的元数据编辑可能被更新覆盖；公钥/UUID更换或卸载重装后需重新配置。不得自动安装或修改浏览器安全设置。

## 测试边界

`node notifications/build-universal.cjs` 生成 Helper。`tests/universal-protocol.cjs` 与 `tests/universal-chain.cjs` 运行真实签名/验签、实际主模块与 Helper 模块、模拟 GM 标签存储及通知接口，覆盖伪造/篡改/过期/重放、序号并发、跨站互斥、关闭模拟 PTA 后其他站点继续检查、撤销与篡改猴无回执。

这些不是实际篡改猴/脚本猫、关闭标签、页面冻结或 OS 通知验收。协议不能克服宿主拦截消息、浏览器进程退出或系统休眠。

通用模式在 `pagehide` 后永久停用该文档实例，阻止从 BFCache 返回时继续旧通知事务。通过浏览器后退恢复的页面需要刷新才重新参与提醒。管理器已排队但未完成的 GM 写入与同标签新文档的排序仍需实机验证；目前不承诺跨生命周期严格一次通知。

若导航到不允许注入脚本的页面后，管理器仍保留旧的非零标签锁记录，其他实例会保守等待；关闭该标签后才可恢复。这个管理器生命周期行为必须实机验收，当前不承诺后台提醒可靠性。

已修复确定的卸载清理问题：参与过互斥的实例在 `pagehide` 立即提交零票据，普通异步回调保持停用，不再因 alive 检查阻止清理。`tests/universal-lifecycle.cjs` 覆盖持锁/申请时离开且没有新脚本页面接管，以及异步 FIFO 写入。依赖管理器按调用顺序应用同标签写入；乱序或丢失卸载写入仍是实机验收阻断，不保证可靠性。

## 安装入口

- [PNC 2.1.0](https://raw.githubusercontent.com/NeuronCState/PTA-Neuron-Copilot/main/PNC.user.js)
- [PNC Helper 1.0.0](https://raw.githubusercontent.com/NeuronCState/PTA-Neuron-Copilot/main/PNC%20Helper.user.js)

Helper 暂不配置自动更新地址，避免覆盖可选后台模式的手动元数据；普通模式公钥独立存储，更新代码不会覆盖。手动升级后请核对配对。

### 输入框配对

配对输入框为管理器菜单触发的浏览器原生对话框，不是网页 DOM。启动时捕获用户脚本隔离环境的对话框引用，不使用 unsafeWindow；实际篡改猴/脚本猫的隔离和弹窗行为仍需实机验证。只在自己管理器的 Helper 菜单操作，不向网页索要的框粘贴凭据。配对仅接受合法 P-256 公钥，拒绝私钥和额外字段。不得将此模拟测试视为任意恶意网站上的绝对隔离保证。

### 配对码复制反馈

只有浏览器 `navigator.clipboard.writeText` 的 Promise 成功完成时，按钮才显示“已复制 ✓”。若浏览器接口不可用或拒绝，则尝试脚本管理器 `GM_setClipboard`；该接口的回调或 Promise 完成只显示“已请求复制”，请自行粘贴检查。不要将管理器回调等同于成功：ScriptCat [4bc187a 的实现](https://github.com/scriptscat/scriptcat/blob/4bc187aaeababf6daa38bb66c67047147464484d/src/app/service/content/gm_api/gm_api.ts#L1520-L1556) 在内部请求成功和失败时都会回调，`GM.setClipboard` 的 Promise 包装也会因此 resolve。异常、拒绝或 5 秒未完成显示未确认，不输出底层错误中的信息；迟到的回调不会覆盖超时状态。本功能不读取用户剪贴板，仅写入配对验证公钥，不复制私钥或 API Key。

`node tests/helper-copy-feedback.cjs` 覆盖上述成功、失败与模糊结果路径。测试使用模拟接口，不能替代实际安装版本的 ScriptCat / Tampermonkey 浏览器验证。

### Helper 测试诊断


扩展菜单新增“测试诊断”。打开只读取本地状态，显示配对、暂停、签名设置、题集缓存时间与数量、阈值内未截止数量、本页面最近同步消息及验签结果。不会展示密钥、账号、题集标题或答案。同步结果会区分无消息、缺设置、关闭/撤销、缺目录、账号不匹配、空目录和可用目录，不再把收到任意签名包一律称为“已同步”。

- 输入 `1` 请求同步：只在 PTA 页面发送不含数据的同步请求；不自动启用提醒、不清除数据、不声称请求成功即已同步。其他网页提示打开 PTA。
- 输入 `2` 测试通知：再次确认后发送一条通用测试消息，不修改暂停状态和正式通知去重记录。分别显示明确失败、管理器已创建、仅已请求；均不能证明操作系统实际展示。
- 取消或空输入只关闭，不产生通知或改变状态。历史同步数据来自 Helper 独立存储，本页接收/验签诊断在刷新后重新开始；旧缓存仍可能不反映 PTA 后续延期。

`node tests/helper-diagnostics.cjs` 覆盖上述状态、取消、明确授权后测试、结果区分和敏感字段不输出。使用模拟管理器，未替代真实浏览器/系统通知验收。

本次需要同时手动更新 PNC 2.1.0 和 Helper 1.0.0，然后刷新 PTA 页面；只保留各一份启用的脚本。已有配对公钥与主签名键保持原存储键，代码不主动重置；若管理器将其安装成新副本，请停用旧副本并重新配对。

### beta.6：同步通道兼容修复

PNC 和 Helper 增加 PTA 页面内的 DOM 字符串事件备用通道，和窗口消息并行发送同一个签名包。需同时升级两个脚本。窗口消息不再依赖脚本沙箱 `Window` 包装对象的相等性；信任仍来自手动配对的公钥验证，不来自页面、事件来源对象或备用事件名称。Helper 诊断增加“接收通道”。两条通道都可能被宿主阻断，签名发送不等于收到或系统通知送达。

`node tests/universal-transport.cjs` 用实际主/Helper模块和独立存储验证不同 Window 包装、仅备用通道、双通道、伪造、重复、来源和长度限制。未在真实篡改猴或脚本猫中复现根因或完成验收。

### 点击截止通知直达题集

每条截止通知只对应一个题集，通知正文包含该题集名称与剩余时间，点击由管理器打开 `https://pintia.cn/problem-sets/{数字ID}/exam`。多题集不再共用一个通知和首页链接；每轮最多请求三条，剩余题集留到下一轮（通常30秒后）继续检查，不会提前标成已通知。每条使用不同 tag 和原有按题集去重键，未知结果仍不盲目重发。

只使用固定 PTA HTTPS 域名和通过格式检查的数字题集 ID；忽略页面或缓存里的任意 href。不新增凭据或读取其他网站。已创建的旧通知不能改写，新版本也不清除原去重记录以免重复骚扰。手动测试通知不对应真实题集，不自动跳转。

`node tests/notification-targets.cjs` 覆盖通用/可选后台模式的五题集分轮、独立链接与 tag、恶意 ID/href、过期过滤和去重。测试核验传给通知接口的 URL，未代替真实管理器点击与系统通知验收。
