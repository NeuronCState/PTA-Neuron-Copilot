# PNC 2.1.0-beta.1 与 PNC Helper 1.0.0-beta.1

测试分支，未经真实脚本猫与系统通知验收，不覆盖稳定版。

- [安装 PNC 2.1.0-beta.1](https://raw.githubusercontent.com/NeuronCState/PTA-Neuron-Copilot/beta/pnc-2.1.0-beta.1/PNC.user.js)
- [查看/安装 PNC Helper 1.0.0-beta.1](https://raw.githubusercontent.com/NeuronCState/PTA-Neuron-Copilot/beta/pnc-2.1.0-beta.1/PNC%20Helper.user.js)

两个文件名为 `PNC.user.js` 和 `PNC Helper.user.js`；版本记录在元数据中。主脚本 `@name PTA-Neuron-Copilot` 保留，避免改变既有安装身份与缓存。Helper 名为 `PNC Helper`，采用独立的 1.0.0-beta.1 版本序列。

采用脚本猫独立后台脚本。关闭 PTA 标签后可依据最后同步的截止时间检查；浏览器退出、休眠、扩展暂停时不能实时提醒，恢复运行后只检查尚未截止的题集。系统静音/权限可能阻止实际展示，不应作为唯一提醒渠道。

## 手动绑定及授权范围

只需一个后台辅助脚本，不再使用前台桥或网页 `postMessage`。

1. 安装主 beta，主脚本保持原 `@name` / `@namespace` 和 GM 存储身份，不添加 `@storageName`，不迁移旧缓存。
2. 在脚本猫管理器中找到**已安装主脚本的 UUID**（不是脚本猫网站编号、脚本名称或 namespace）。实际界面位置待实机核实，不能猜填。
3. 编辑仓库根目录的 `PNC Helper.user.js`，将 `@storageName REPLACE_WITH_MAIN_SCRIPT_UUID` 替换为该 UUID。这个步骤由用户手动执行，**不要公开上传含本机 UUID 的定制文件**。
4. 绑定意味着辅助脚本技术上能够读写整个主脚本 GM 存储，不是仅有提醒键权限。本候选代码只访问 `pnc-reminder-v2:` 的 `control`、`snapshot`、`revocation`、`state`、`status` 五个键，不枚举、不读取其他键，不联网、不读取凭据。须在理解此范围后决定是否安装。
5. 只安装并启用**一份**后台辅助脚本；重复副本之间没有存储事务锁，不支持多个后台实例同时运行。辅助脚本自动更新可能覆盖手动绑定，更新后须核对 UUID，不能假设永久保留。
6. 在 PTA 读取并验证当前账号目录，然后于主脚本设置底部打开“倒计时提醒（Beta）”，选择提前 1–30 天。系统/脚本猫通知权限由用户按提示允许。默认不开启、不发通知。其他管理器明确不支持此后台方案。

## 行为

- 严格小于所选天数，且尚未截止才提醒。仅使用本地缓存，不在后台查询新题集或延期。
- 超过 500 条可同步，最多 10000 条；超过上限明确报错并清空提醒快照，暂停提醒，不静默截断。主脚本写入后，后台状态含快照 ID 作为读取回执。
- 同账号/题集/截止时间/阈值创建成功后不重复。每轮最多汇总 20 个题集，前 4 个展示名称，可能出现在锁屏上。
- 通知创建失败按指数退避有限重试，最多 5 次；状态提示失败，可手动关闭再开启重新尝试失败项。已成功创建的通知不会因此重发。崩溃发生在请求后但记录结果前，恢复后可能重发一次，这是避免永久丢失提醒的取舍。
- 主脚本请求明确返回未登录或证实账号变化时写入撤销标记，后台停止旧配置，须重新验证后手动启用。后台发现快照账号与授权账号不符同样撤销。
- **全部 PTA 标签关闭时无法得知外部注销、服务器会话过期或截止时间修改**，只代表最后确认账号的缓存。不能把后台运行等同于实时登录状态验证。仅关闭页面不撤销提醒。
- 控制命令使用唯一 ID，后台以 GM 存储当前值为准，不按毫秒时间排序；通知前再次核对控制和撤销状态。关闭后不会新发请求，但已在通知 API 中的请求无法撤回。

## 验证与依据

`node notifications/build.cjs` 重建辅助脚本。`node tests/deadline-notifications.cjs` 运行真实主提醒模块→模拟 GM 存储→后台模块的链测试，覆盖非用户事件拒绝、容量、去重、失败重试、撤销及并发。不是实机脚本猫、操作系统通知或浏览器关闭标签测试。

依据官方 ScriptCat 源码 `src/pkg/utils/utils.ts:getStorageName`：显式 `metadata.storagename[0]`，否则 `script.uuid`；验证版本 `4bc187aaeababf6daa38bb66c67047147464484d`。手动绑定应在用户实际版本复核后再开放。
